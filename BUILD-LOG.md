# Devlog Timer build log

The first build (cap meter, today tracker, rating balance, devlog template)
predates this log - see README.md for the feature list and screenshot.png for
how it shipped.

## 2026-10-24 - safety, cadence, and installability refinements

1. Tab-close guard: a `beforeunload` listener now asks for confirmation when a
   running session is past the 8h red line, so a stray Cmd-W can't silently
   kill the nudge. Threshold lives in `WARN_AT_MS` next to the other rules.
2. Devlog history strip: the Today card lists the last 5 "I posted a devlog"
   taps with timestamps, newest first (persisted as `state.devlogLog`, trimmed
   to 5 on every post). Empty state reads "none yet - your last 5 will show
   here". Existing localStorage states migrate cleanly via the defaults.
3. Today rollover guard: when the stored day differs, under-cap minutes reset
   with the day as before, but uncapped overflow above 600 now carries into
   the new day instead of being wiped at midnight. The Today card also shows
   a red "over the cap by Xh Ym - post now" line whenever the live day total
   (banked minutes + running session) is past the cap. `CAP_MINUTES` moved
   above the rollover block so the carry can reference it.
4. PWA-lite: added `manifest.json` (name, standalone display, dark
   `theme_color`/`background_color` #0d1220, start_url/scope ".") and linked
   it from index.html with a matching `theme-color` meta. Icons are 192px and
   512px star-on-dark PNGs generated by a stdlib-only python3 script (zlib +
   math, no struct, 2x2 supersampled, rounded corners, star in the accent
   #f5a742) - no data-URI shortcuts, which manifests don't accept.
5. Verified locally: `node --check script.js` passes, manifest parses as JSON,
   both PNGs confirmed as valid 8-bit RGBA at the right dimensions. The
   beforeunload prompt and the install prompt still need a manual browser
   pass (see README).
